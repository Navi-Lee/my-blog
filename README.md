# Navi Lee's Blog

这是我的个人博客项目。

这里会放一些日常随笔、技术记录，以及阶段性的想法整理。相比把内容发在平台上，我更喜欢给自己留一块安静、长期、可以慢慢生长的地方，这个网站就是这样一个空间。

网站里目前主要包含这些内容：

- 首页介绍
- 博客文章
- 关于我
- 社交媒体页

如果你只是想本地看一下这个项目，下面这些就够用了：

```bash
npm install
npm run dev
```

如果你想生成正式版本：

```bash
npm run build
```

这个网站基于 Astro 构建，并使用 Vercel 部署。

欢迎来看看，也欢迎交流。
